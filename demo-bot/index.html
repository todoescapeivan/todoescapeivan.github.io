Qué es

Un asistente que atiende el WhatsApp comercial de un negocio real: entiende el mensaje (texto o audio), decide qué contestar, cobra por transferencia y entrega el archivo digital. Cuando no sabe, deriva a una persona — no inventa.

Esta página publica la lógica de decisión, que es lógica pura: recibe texto, devuelve texto. La capa de red (API de Meta, transcripción, voz) vive en el servidor privado, con credenciales que no se publican.

El método c

La batería cubre saludos, selección de producto, precios, contenido, pagos, erratas de tipeo, texto basura, intento de inyección de prompt y cortesías. Los casos fuera de guion derivan.

Decisiones de diseño

DecisiónPor qué
Guion cerrado para precios y pagosUn número inventado cuesta plata. Lo que no está, se deriva.
Normalizar erratas antes de buscar palabras claveLa gente escribe apurada, con una mano y sin tildes.
La prueba evalúa la respuesta, no el flujoUn cambio de texto que rompe una promesa se detecta antes de publicar.
Voz donde hay conversación, texto donde hay listaUn precio necesita poder releerse; una explicación se escucha.

def flujo_catalogo(texto):
    """Menú de libros por WhatsApp. Devuelve (respuesta, consumido)."""
    t = (texto or "").strip().lower().rstrip(".!")
    if not t or len(t) > 40:
        return "", False
    if t in ("hola", "holaa", "buenas", "buen dia", "buen día", "menu", "menú", "catalogo",
             "catálogo", "productos", "precio", "precios", "info", "que vendes", "qué vendés"):
        return MENU_WA, True
    m = re.match(r"^(?:comprar|quiero|dame|pedir|me llevo|reservar)\s*(?:el\s*)?(?:pack\s*)?([123])$", t)
    if m:
        k = m.group(1)
        pr = PRODUCTOS_WA[k]
        return (f"{pr['nombre']} — {pr['precio']}\n\n{pr['detalle']}\n\n" + PAGO_WA), True
    if t in ("1", "2", "3"):
        pr = PRODUCTOS_WA[t]
        return (f"{pr['nombre']} — {pr['precio']}\n\n{pr['detalle']}\n\n"
                f"Para comprarlo escribí: COMPRAR {t}"), True
    return "", False


def _normalizar(texto):
    """Minúsculas, sin tildes, y corrige los errores de tipeo más comunes."""
    t = (texto or "").lower()
    for a, b in (("á", "a"), ("é", "e"), ("í", "i"), ("ó", "o"), ("ú", "u"), ("ñ", "n"), ("ü", "u")):
        t = t.replace(a, b)
    for mal, bien in (("ola", "hola"), ("hla", "hola"), ("holaa", "hola"), ("preio", "precio"),
                      ("presio", "precio"), ("cuamto", "cuanto"), ("kuanto", "cuanto"),
                      ("komo", "como"), ("kiero", "quiero"), ("komprar", "comprar")):
        if t.strip() == mal or t.startswith(mal + " "):
            t = bien + t[len(mal):]
    return t
